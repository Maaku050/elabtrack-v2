# Phase 13 security assessment

Engineering evidence for the authorized local presentation build; institutional/production approval is separate. This is a repository and isolated PostgreSQL/HTTP/Chromium assessment, not an independent penetration test or deployment certification.

|Boundary|Executed evidence and result|
|---|---|
|Current identity and authority|Real login/logout, refresh rotation/replay/concurrent recovery, revoked sessions, role changes and deactivation. Backend rechecks current active/activated roles; client hides unresolved privileged content. No permanent role caching. Exactly one current-account request per protected pathname remains intentional.|
|Borrowing and physical accountability|Actual PostgreSQL last-unit/contention, sorted account/equipment locks, stale review conflicts, UUID/payload receipts, rollback, conserved stock, partial/mixed return and exact replacements. Borrower cannot record their own return. Full-balance fine resolution remains Admin-only and does not resolve custody/replacements.|
|Notifications and worker concurrency|Recipient scope/current role, durable unique event/recipient records, immutable read-time behavior, bounded worker and abrupt process restart. A real restart failure exposed a notification FK/account/borrowing lock inversion; non-key lifecycle row locks now serialize competing writers while permitting FK KEY SHARE. Deterministic real-lock regression proves both properties.|
|SQL and bounded reads|Parameterized values and fixed report/history source whitelists; search wildcard/input and forged identifier regressions. Server pagination/counts share one SQL statement. Complete financial/custody aggregates survive bounded history previews; event_count remains the complete mutation version.|
|Browser inputs/exports|Untrusted history is text, not executable markup. Actual CSV quoting/newlines/Unicode/formula defenses and refusal above5000 rows. Trusted browser Origin required for mutating endpoints. Central cookie-only refresh and cross-tab/session invalidation remain intact.|
|Images and privacy|Own-only profile mutations, authorized current-image reads, PNG/JPEG input validation, canonical PNG/metadata removal, bounded bytes/dimensions/pixels, hash checks, optimistic version, replay and transactional audit/rollback. No return evidence uploads. Catalog permissions preserved.|
|Database/credentials|Separate bootstrap/migrator/runtime roles; history deletion/update/truncation and unsafe down migrations rejected. Presentation secrets generated into ignored0600 files and passwords never passed in argv. Interactive-only retrieval. Runtime excludes privileged database/mail secrets. No live mail or real-data seed.|
|Recovery and preservation|Real custom-format backup restored into a new isolated54837 volume with29 table digests, sequence states and11 migration records equal. Normal21-table snapshot and accepted Phase7 demo unchanged. Every old verification/demo/restore volume retained.|

The candidate-file scan found no private keys, provider keys, JWTs, bcrypt hashes or private/runtime artifact paths. Review includes original local illustration provenance, fictional screenshot identities and configured placeholder examples; none is a production credential. Final exact repository status and exclusion evidence are recorded with the system report.

Known limits: nineteen inherited frontend warnings remain in shadcn primitives/use-mobile; no warnings were suppressed. The lazy-login test previously raced router initialization during loaded parallel runs; tests now await the actual initialization signal without changing assertions/timeouts or preloading away the route. Cold builds/tests can still be slower under WSL resource contention. The owner's historical unmatched GET500 lacks its request path and cannot be attributed truthfully; current `/`, `/favicon.ico` and a nonexistent API route return404, readiness200. No speculative fix was applied.

Bounded notification emission still scans historical source unions; the measured isolated query and dataset sizes are in `docs/ux/verification/phase13/query-performance.json`, not a production throughput claim. Internal mutation validation intentionally retains complete per-loan aggregates/history; extremely long individual loans need future capacity profiling. Neither limitation truncates stock or finance authority. No Redis, queues or speculative index/schema change was introduced.

Real Safari/Firefox/physical-device and screen-reader sessions, production TLS/proxy/cookie configuration, live Brevo delivery/recovery and institutional terms/domains were not verified. Official terms/current consent and activation remain enforced live-use gates; demonstration publication/activation never enter normal data. Production due-soon/repeat cadence and damaged-original repair/disposal authority remain open. A demonstration classification of PAID records fictional offline FSMO resolution, never payment processing.
